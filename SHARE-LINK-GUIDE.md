# 🔗 Share Room Link - How It Works

## ✅ Improved Share Link Feature

The share link feature has been enhanced to make it easier for users to join rooms!

## How to Share a Room

### Step 1: Create or Join a Room
1. Click "Watch Together" button
2. Enter your name
3. Click "Create Room" or "Join Room"

### Step 2: Copy the Share Link
Once you're in a room, you'll see:
- **🔗 Share Room Link** section
- A text box with the full URL
- **📋 Copy Link** button

Click the **"Copy Link"** button to copy the link to your clipboard.

### Step 3: Share the Link
Share the link via:
- ✅ WhatsApp
- ✅ Email
- ✅ SMS
- ✅ Any messaging app
- ✅ Social media

## How Others Join Using the Link

### Method 1: Auto-Join (Recommended)
1. **Click the shared link** (or paste it in browser)
2. **Enter your name** when prompted
3. **Automatically joins the room!** ✨

### Method 2: Manual Join
1. Open the link in browser
2. Click "Watch Together" button
3. The Room ID is already filled in
4. Enter your name
5. Click "Join Room"

## Link Format

The share link looks like this:
```
http://localhost:5173/movies/tt1234567?room=abc123
```

Where:
- `tt1234567` = Movie ID
- `abc123` = Room ID

## Features

✅ **One-click copy** - Easy to copy link
✅ **Auto-join** - Automatically joins when link is opened
✅ **Works on any device** - Share via any app
✅ **Room ID in URL** - Easy to remember/share

## Troubleshooting

### Link doesn't work?
- Make sure the room is still active (not expired)
- Make sure backend server is running
- Check that the room hasn't reached max users (10)

### Auto-join not working?
- Make sure you enter your name when prompted
- Wait a few seconds for connection to establish
- If it fails, use manual join method

### Can't copy link?
- Click on the text box to select all text
- Press Ctrl+C to copy manually
- Or right-click and select "Copy"
